# academybugs-qa-portfolio
Projeto de portfólio em QA com foco em testes manuais no AcademyBugs. Inclui planejamento de testes, cenários em BDD/Gherkin, documentação de defeitos com passos para reprodução e sugestões de melhoria. Desenvolvido para aplicar e demonstrar conhecimentos em qualidade de software, análise de comportamento e documentação de testes.
