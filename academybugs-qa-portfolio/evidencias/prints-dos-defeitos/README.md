# Evidências dos defeitos

Salve nesta pasta apenas capturas de tela ou vídeos reais obtidos durante a reprodução.

## Sugestão de nomes
- `BUG-001-card-tamanho.png`
- `BUG-004-total-frete.png`
- `BUG-007-validacao-pagamento.png`

## Boas práticas
- Capture a tela no momento em que o comportamento ocorre.
- Sempre que possível, mostre o contexto necessário para entender o defeito.
- Evite capturas excessivamente cortadas.
- Oculte nomes, e-mails, endereços ou outros dados pessoais.
- Não use imagens ilustrativas como se fossem evidências reais.
