# Projeto de QA — AcademyBugs

Portfólio de estudos em Quality Assurance (QA), desenvolvido a partir da exploração manual do site [AcademyBugs](https://academybugs.com/find-bugs/).

## Objetivo

Demonstrar práticas de planejamento de testes, elaboração de cenários em BDD/Gherkin, registro de defeitos, documentação de melhorias e organização de evidências.

> **Transparência:** este é um projeto de estudo. Os itens documentados foram descritos a partir das observações registradas durante a exploração. Antes de publicar a versão final, reproduza cada comportamento, revise os passos e adicione evidências reais. Não marque testes como executados nem invente resultados.

## Escopo

- Exploração manual de páginas e fluxos da loja.
- Verificações funcionais, de interface, validação de campos, navegação e carrinho.
- Elaboração de cenários em formato BDD/Gherkin.
- Documentação de defeitos e sugestões de melhoria.
- Registro de evidências e resumo da execução, após a validação.

## Estrutura do projeto

## Técnicas e conhecimentos demonstrados

- Testes exploratórios e testes manuais.
- Escrita de cenários com Dado / Quando / Então.
- Análise de comportamento esperado versus observado.
- Documentação de defeitos com passos reproduzíveis.
- Observação de fluxos de carrinho, formulários, navegação e elementos visuais.
- Organização de documentação para consulta e rastreabilidade.

## Como consultar

1. Leia o plano de testes.
2. Consulte os cenários BDD.
3. Compare cada cenário com o relatório de defeitos usando os identificadores CT e BUG.
4. Consulte as sugestões de melhoria.
5. Veja o resumo da execução quando estiver preenchido com resultados realmente verificados.
